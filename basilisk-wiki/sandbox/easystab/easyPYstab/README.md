
# easyPYstab : a python-based toolbox for instability problems in fluid mechanics.

 This project was started in december 2025, as a translation of the previous Octave-based project "easystab" (initiated by J. Hopfner, 2014 ; maintained by D. Fabre up to 2025)

This version contains programs to be used along with the course 
["Introduction to Flow instabilities"](/sandbox/easystab/M2DET/Instabilities.md)
 in Master DET (Toulouse).
